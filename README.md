# DeepFake Detection Forensic Tool

A professional-grade video forgery detection system using Deep CNN and LSTM architectures to identify manipulated content and localize forensic evidence.

## 🚀 Deployment (Coolify / Docker)

This project is container-ready. To deploy:
1. Push to GitHub.
2. Connect to **Coolify**.
3. Set environment variables (`SECRET_KEY`, `DEBUG`, `ALLOWED_HOSTS`).
4. Deploy!

## 🛠️ Features
- **Registration & Login**: Secure access for forensic analysts.
- **Deep Analysis**: Frame-by-frame forgery probability scoring.
- **Visual Evidence**: Automatic localization and highlighting of forged regions.
- **Model Training**: Interactive module to train the AI on new datasets.
- **Responsive Dashboard**: Quick access to all tools and recent results.

## 📦 Tech Stack
- **Backend**: Django (Python)
- **Computer Vision**: OpenCV
- **Machine Learning**: Scikit-learn (RandomForest)
- **Frontend**: Glassmorphism CSS, Vanilla JS
- **Production**: Gunicorn, WhiteNoise, Docker
